## What automatic means

The daemon uses the assigned container proxy, or the selected device proxy when the container has none. It snapshots the profile and effective proxy configuration around the lookup and before private-draft publication. An unavailable proxy, inconsistent assigned country, frozen identity, changed configuration or canceled request returns failure and leaves the previous draft available. Frontend country/model strings are not accepted as automatic observation evidence.

Country comes from one IP-geolocation service response. Locale and carrier are country-catalog suggestions; they are not measurements of the SIM operator or language. The city is a matching catalog city in the observed timezone, otherwise a compatible catalog suggestion. A missing timezone uses the country default; an incompatible observed timezone is rejected. The private provenance includes these source distinctions and excludes proxy credentials, endpoint and observed IP.

The observation must be at most 60 seconds old when constructing the draft. An editor left open is not continuously refreshed, and Check/Save does not repeat IP geolocation. A proxy may externally rotate without changing its configured URL. Protected Open still requires its separate live network checks. Automatic chooses a random compatible catalog model/iOS, not necessarily the newest version, and does not change the physical phone or install another iOS.

UDID, Platform UUID, IDFV, IDFA and other required identifiers are generated and visible. A generic model may intentionally omit IMEI; denied ATT intentionally uses zero IDFA. Manual mode allows editing while the identity is unlocked; it freezes before a protected launch is armed, even if a later launch step fails. Existing saved values are loaded without automatic replacement. Incomplete older drafts are flagged, can be repaired before use, and cannot save identity changes while required fields are missing.
