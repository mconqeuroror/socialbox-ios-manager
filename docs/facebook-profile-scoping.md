# Facebook profile scoping and activation boundary

The generator accepts an explicit registered app type for unsaved identity drafts. Missing app type through the existing public wrappers retains the exact legacy Reddit document shape. Facebook drafts carry `appType: facebook`; catalog model/iOS, locale, proxy-country consistency, common identifiers, blocked App Attest/DeviceCheck defaults, and installation-time staggering use the existing generator. Random identity editing derives the app from the persisted profile and preserves both explicit ownership and legacy field absence. A caller cannot change ownership through identity choices.

The `reddit` section in Facebook drafts remains **internal schema compatibility only**. Its install UUID, external installation UUID, timestamp, device-name and font fields do not identify, regenerate or cover Facebook/Meta installation IDs, Keychain entries, SDK IDs or outbound request fields. The Facebook binary/storage audit and runtime acceptance must establish those independently. These generated values are not evidence of Facebook account isolation.

Facebook creation now has a read-only preflight before dispatch, proxy-region lookup, operation ownership, identifier allocation, identity reservations, proxy registration, profile publication, pool assignment or clone installation. It checks Facebook's descriptor and private source status. Missing or encrypted source fails with a Facebook-specific import instruction; an imported source still fails while `runnable` is false. The Reddit wrapper retains its previous admission order and source behavior.

Clone ensure/sync now construct the manager from the loaded profile's immutable owner. Ordinary Create dispatch passes the requested app type. Facebook operation, identity and IPA-export summaries carry app type; legacy Reddit result shapes remain unchanged. Export construction selects the profile's descriptor and its existing descriptor-owned export path.

This unit does not enable Facebook execution or change the single-active-app lease, process kill/drain sequence, rotate/from shortcut, replacement, backup restore, deletion or recovery journals. The export branch still relies on that existing process/network sequence. These branches require a separate audited app-aware lifecycle before Facebook can become runnable. Source removal remains a Reddit-only launcher action because its daemon branch is still Reddit-specific.

Validation uses the actual generator/catalog/loader/validator and the shipped registry admission, ensure/sync and identity-candidate method bodies with inert service boundaries. Isolated active/inactive registry copies exercise positive ownership routing and early rejection without changing shipping activation. Main operation/identity publication functions are executed against a synthetic in-memory store. These tests do not install an app, authorize a lease, access a Facebook account or prove device behavior.
